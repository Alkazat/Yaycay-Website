# Yaycay website: Nano Banana image briefs

Every AI-generated image the site expects, with the **exact filename and folder** to save it to, the aspect ratio, and a ready-to-paste prompt. Generate each one, save it at the path shown (under `public/...`), and hand the files back. The site already references these paths, so once the files exist they render automatically (the `ImageSlot` placeholders disappear).

## How to use this document
1. Pick an image below.
2. Copy the **style preamble** for its type (Photo or Illustration), then paste the image's **Prompt** after it.
3. Generate at (or above) the stated aspect ratio, export, and save to the **Save as** path.
4. Place files in `Yaycay-Website/public/...` exactly as written (create folders as needed).

## Non-negotiable rules (apply to every image)
- **No identifiable faces of children.** Shoot/illustrate from behind, three-quarter, in motion blur, or cropped above the face. This is a legal and brand rule, not a preference.
- **No stock-photo gloss.** Documentary and warm, never posed-corporate.
- **Allergy never reads as "safe".** No image should imply a guarantee; we show flags and checks, not safety badges.
- **British/Australian spelling** in any in-image text.

## STYLE PREAMBLE A — Documentary photo
> Documentary family-travel photography, photorealistic, 4K. Warm cream-and-sand colour grade (paper white #fefcf6, sand #e3ddd0). Natural available light; golden hour where noted. Candid and real, never stock-posed, no glossy commercial sheen. CRITICAL: no identifiable faces of minors — shoot from behind, three-quarter, motion blur, or crop above the face. The mood is calm, present, "actually on holiday".

## STYLE PREAMBLE B — Flat spot illustration / diagram
> Flat vector spot illustration in the Yaycay "box-art" locked style: 2.5px deep-navy (#04223f) outlines, flat fills only, generous negative space, a slight hand-drawn wobble. NO gradients, NO 3D, NO photographic texture, NO drop shadows. Palette: royal navy #073d72, sky blue #2a96d8, sunshine #f7aa15, coral #ff6f4d, meadow #46b25e, cream #fbf7ec, sand #e3ddd0. No identifiable faces. Clean, friendly, modern picture-book feel.
